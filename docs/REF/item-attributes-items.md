The `/items` endpoint has these two HTTP methods you can interact with:

* [POST](https://ke.docs.digitax.tech/reference/post_items#/)
* [GET](https://ke.docs.digitax.tech/reference/get_items#/)

The `/items/{item_id}` endpoint has these three HTTP methods you can interact with:

* [PUT](https://ke.docs.digitax.tech/reference/put_items-item-id#/)
* [GET](https://ke.docs.digitax.tech/reference/get_items-item-id#/)

Below are the attributes used in the API requests and responses above.

## Attributes table

| Attribute ID         | Required                              | Data Type | Description - Sample (JSON)                                                                                                                                                  |
| -------------------- | ------------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| item\_id (id)        | For GET (single item), PUT and DELETE | string    | **item\_id** represents the UUID (Item ID) as generated by FTA - `"T9mXFPgUYn"`                                                                                              |
| active               | Yes                                   | boolean   | Represents whether the item concerned is used OR unused - `true`                                                                                                             |
| item\_class\_code    | Yes                                   | string    | Represents Item Classification Code. See [Item Classification codes table](https://ke.docs.digitax.tech/docs/items-item-classification-table#/) for context - `"5059690800"` |
| item\_type\_code     | Yes                                   | string    | Represents Item Type Code. See [Item Type codes table](#item-type-codes) for context - `"1"`                                                                                 |
| item\_name           | Yes                                   | string    | Represents the Item Name `"test material item 3"`                                                                                                                            |
| origin\_nation\_code | Yes                                   | string    | Represents the code of the item's origin (Nation). See [Country Codes table](#country-codes) for context - `"KE"`                                                            |
| package\_unit\_code  | Yes                                   | string    | Represents the item's packaging unit. See [Packaging Unit table](#packaging-unit-codes) for context - `"NET"`                                                                |
| quantity\_unit\_code | Yes                                   | string    | Represents the Quantity Unit Code. See [Quantity Unit table](#quantity-unit-codes) for context - `"BA"`                                                                      |
| tax\_type\_code      | Yes                                   | string    | Represents the Taxation Type Code. See [Taxation Type table](#taxation-type-codes) - `"D"`                                                                                   |
| default\_unit\_price | Yes                                   | number    | Represents the Default Unit Price - `3500`                                                                                                                                   |
